# Automation Testing Framework

An automation testing framework for the eCommerce platform built using **Python**, **PyTest**, and **Selenium WebDriver** following the **Page Object Model (POM)** design pattern.

This project automates critical functionalities such as user registration, login validation, product search, and data-driven testing to ensure application reliability and functionality.

---

# Features

-  Automated Login Testing
-  Negative Login Validation
-  User Registration Testing
-  Product Search Functionality Testing
-  Data-Driven Testing using Excel
-  HTML Test Report Generation
-  Screenshot Capture on Failures
-  Page Object Model (POM) Architecture
-  Reusable Utilities and Configurations
-  Cross-browser Automation Support
